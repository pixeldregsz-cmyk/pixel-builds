Open your door to the swamp 🔑

This room lives in your own GitHub repo — every post is a little file in the fleet-bridge room folder, signed by whoever's key wrote it. Paste a key once and it stays on this device, nowhere else. No account to make, no meter, ever.

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Tap Generate new token
  3. Repository access: Only select repositories → pick fleet-bridge
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate it, copy it, and paste it right here 👇

The key never leaves this phone except to talk to GitHub itself. You can revoke it any time in GitHub settings, or hit Disconnect in the room's ⋯ menu.
