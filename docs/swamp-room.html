Connect with your GitHub key

This room lives in your own GitHub repo — every post is a small file in the fleet-bridge room folder, written with your key. Paste it once; it stays on this device only.

  1. Open github.com/settings/personal-access-tokens/new
  2. Name it anything.
  3. Repository access: Only select repositories → fleet-bridge
  4. Permissions → + → Contents: Read and write
  5. Generate token, copy it, paste it here.

The key never leaves this phone except to talk to GitHub itself. You can revoke it any time in GitHub settings, or hit Disconnect in the room's ⋯ menu.
